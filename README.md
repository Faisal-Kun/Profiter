# Profiter

**Profiter** adalah sistem pencatatan dan pengelolaan keuangan UMKM berbasis web.

Aplikasi ini dibuat untuk membantu pemilik usaha dalam mengelola produk, produksi, penjualan, pengeluaran, serta melihat laporan keuangan dengan lebih mudah.

## ✨ Fitur

- 📊 Dashboard
- 📦 Manajemen Produk
- 🏭 Pencatatan Produksi
- 🛒 Pencatatan Penjualan
- 💸 Pencatatan Pengeluaran
- 📈 Laporan Keuangan
- 🧮 Perhitungan HPP dan laba
- 🖼️ Foto Produk

## 🛠️ Teknologi

- PHP
- Laravel
- MySQL
- Bootstrap
- JavaScript
- HTML & CSS
